# 공식 인구 전망 · 전국 2072년까지

## 표시 기간 확장

전국과 17개 시·도 모두 2025~2072년(48개 연도)을 표시합니다. 2053년 이후 지도 색상과 성별·연령계층별 정보도 제공하며 지역을 변경해도 선택 연도가 유지됩니다. 전국 2072년 총인구는 36,222,293명, 65세 이상은 17,270,735명입니다.

2026-11-02에 [KOSIS 온라인간행물](https://kosis.kr/upsHtml/online.do?pubcode=PJ&isOnline=Y)의 **장래인구추계 시도편(2022년 기준) → [부록] 100년 추계(중위,고위,저위), 2052~2122**에서 원본 엑셀 2개를 추가 확보했습니다.

- `data-source/projection/long-range/19020905.xlsx`: 9-5. 시도, 성 및 5세 계급별 인구. `9.5중위` 시트의 2052~2072년만 사용합니다. 0~14세, 15~64세, 65세 이상은 5세 구간을 합산합니다.
- `data-source/projection/long-range/19020901.xlsx`: 9-1. 시도별 인구 및 구성비. 참고 원본으로 보관하며 화면 값의 산출에는 9-5를 사용합니다.
- 원본의 고위·저위 시나리오와 2073~2122년은 보관만 하고 화면에는 사용하지 않습니다.
- 기존 자료와 겹치는 2052년의 모든 지역·인구 항목 및 전국 2052~2072년 값을 대조했습니다. 2025~2072년 전체에 대해 시·도 합계와 전국값, 성별 합계, 연령계층 합계가 일치합니다. 임의 외삽이나 전국 인구의 비례 배분은 없습니다.

2026-11-02, 사용자가 선택한 방식에 따라 평균 변화율을 반복 적용하던 화면을 공식 시·도 장래인구추계 표시로 교체했습니다. 자체 코호트 모형 또는 머신러닝을 새로 학습한 결과가 아닙니다.

## 통계 기준

- 출처: KOSIS 인구로 보는 대한민국 지표와 공식 온라인간행물의 100년 추계 부록. 모두 2022년 기준 중위 가정이며 화면에서는 2025~2072년을 사용합니다.
- [공식 작성 방법 및 시도편 설명](https://mods.go.kr/board.es?act=view&bid=207&list_no=431113&mid=a10301010000): 2022년 인구총조사를 기초로 출생·사망·이동 추이를 반영한 전망입니다.
- 2025년도 실제 주민등록인구가 아니라 이 추계의 전망값입니다. 별도 모드의 주민등록인구(연말, 외국인 제외)와 직접 접합하지 않습니다.
- 총인구·남자·여자, 0~14세와 65세 이상 공표값을 수집합니다. 15~64세는 총인구−유소년−고령인구로 계산합니다. 연령과 성별은 별도 구분표이며 성별×개별 연령 교차표를 제공하는 것은 아닙니다.
- 연령별 생존확률·출산율·순이동률을 본 앱이 별도로 수집하거나 다시 적용하지 않습니다. 이를 반영한 공식 결과를 사용합니다. 출생·사망 수의 평균을 공식 결과에 추가하면 이중 반영되므로 추가하지 않습니다.
- 시·군·구로 비례 배분하거나 추계가 없는 지역을 임의 보간하지 않습니다. 지도는 KOSTAT 2018 경계로, 통계 기준 경계와 차이가 있을 수 있습니다. 명칭은 강원·전북 특별자치도 명칭으로 표시합니다.

## 재현 및 검사

```powershell
node scripts/download-projection.mjs
node scripts/import-projection.mjs
node --test tests/official-projection.test.mjs
```

다운로드는 공개 KOSIS 페이지 54개(전국 및 17개 시·도 × 3지표)와 장기추계 엑셀 2개이며 인증키가 필요 없습니다. 각 폴더의 `manifest.json`에 URL과 수집 시각을, 생성 JSON에는 원본 체크섬도 기록합니다. 가져오기는 지표명·시나리오·연도·정수 인구·남녀 합계·연령계층 합계·전국과 시도 합계·중복 기간 일치를 검사하고 실패하면 생성 파일을 덮어쓰지 않습니다.

확인값: 전국 2025년 총인구 51,684,564명, 2050년 총인구 47,106,960명, 2050년 65세 이상 18,907,853명. 이는 선택한 공식 추계 시계열의 값으로 미래 확정 인구가 아닙니다. 전망은 출생·사망·이동 가정과 차기 공표에 따라 달라질 수 있습니다.

기존 `src/data/forecast.mjs`는 과거 평균 변화율 실험 코드로 보관하며 현재 전망 화면에는 사용하지 않습니다. 장기 변화와 시·군·구 주민등록인구 화면은 유지합니다.
